# Coding Rules

1. **Component-Based Development**: Build modular, reusable components in `src/components/`.
2. **Data-Driven**: Tách data ra khỏi UI logic (`src/data/`). Tránh hardcode content.
3. **Tailwind First**: Use utility classes. Use `tailwind-merge` and `clsx` for dynamic styling.
4. **Animation Standards**: Use Framer Motion for all micro-animations and transitions.
5. **SEO & Accessibility**: Always use semantic HTML5 tags and ensure basic ARIA support.
6. **Responsive Design**: Ensure perfect layout on Mobile, Tablet, and Desktop.
7. **Clean Code**: Document complex logic and follow consistent naming conventions.
