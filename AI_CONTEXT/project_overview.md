# Project Overview: Long Tech Portfolio

## Goal
Build a professional personal technology website to showcase skills, projects, and a tech blog.

## Target Audience
- Recruiters and potential clients.
- Tech enthusiasts and fellow developers.
- AI and Automation learners.

## Core Features
- **Portfolio**: About, Skills, Experience, Projects.
- **Tech Blog**: Specialized in Python, AI, Automation, Power Query, VS Code, Ollama, Claude Code.
- **Download Area**: Source code, Tools, Documents.
- **Contact**: GitHub, Facebook, Zalo, Email.
