# UI Style Guide

## Theme: Modern Tech Portfolio
- **Style**: Dark mode, Cyber Technology, Minimal, Glassmorphism, Neon effects.

## Color Palette
- **Background**: `#020617` (Deep Navy)
- **Primary**: `#3b82f6` (Blue)
- **Accent**: `#06b6d4` (Cyan)
- **Highlight**: `#8b5cf6` (Purple)

## Typography
- **Main font**: Inter (Clean, modern sans-serif)
- **Code font**: JetBrains Mono (For snippets and technical flair)

## Interactive Elements
- **Glow Effects**: Applied to primary buttons and featured project cards.
- **Animations**:
    - Typing effect for Hero titles.
    - Fade-up and slide-in on scroll (Framer Motion).
    - Smooth hover transitions on interactive components.
- **Background**: Subtle particle effect or mesh gradient.
